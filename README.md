📘 Expo Judge Pro — User Guide

Digital Stall Evaluation System for Engineering & Innovation Expos

Expo Judge Pro is a mobile-friendly judging tool designed to help judges evaluate expo stalls quickly, accurately, and professionally. The app allows judges to score projects, track rankings, and generate an official Final Judgement Report PDF.

1️⃣ Purpose of the App

Expo Judge Pro helps judges:

Evaluate stalls using a standardized scoring system

Record strengths and feedback

Automatically rank contestants

Identify Top 3 winners

Detect Best Innovation Award

Generate a professional final judging report

The system replaces manual paper judging sheets.

2️⃣ Opening the App

The app works on:

📱 Android phones

📱 iPhones

💻 Laptop / Desktop browsers

Steps:

Open the app link.

Add it to your mobile home screen (recommended).

Start entering stall evaluations.

The app works offline once opened.

3️⃣ Initial Setup (Before Judging Begins)

At the beginning of the judging process, enter the following details:

Expo Name
Example:
National Engineering Project Expo 2026

Judge Name

Panel / Committee

These details will automatically remain the same for all stalls.

4️⃣ Evaluating a Stall

For each stall, fill the following:

Stall Details

Stall Name

Department

Stall Number

Team Members (optional)

5️⃣ Scoring Criteria

Each stall is evaluated using 5 scoring categories:

Category	Description
Innovation	Originality and creativity
Practical Use	Real-world applicability
Technical Quality	Engineering depth and accuracy
Presentation	Clarity and explanation
Future Scope	Potential for future development

Each category is scored:

⭐ 1 to 5 stars

The system automatically calculates:

Total Score

Average Score

6️⃣ Judge Notes & Feedback

Judges can add qualitative feedback:

Strengths

Key advantages of the project

Improvements

Suggestions for improvement

Notes

Additional observations

Final Remark

Overall evaluation summary

The app can also auto-generate remarks based on scores.

7️⃣ Saving Stall Evaluation

After completing scoring:

Option 1

Save

Stores the stall evaluation.

Option 2

Save & Next

Stores the evaluation and prepares the form for the next stall.

Previously evaluated stalls remain visible in the Saved Stalls List.

8️⃣ Editing Previous Evaluations

Judges can:

Navigate to previous stalls

Edit scores

Update comments

Save changes again

This allows judges to review decisions anytime before finalization.

9️⃣ Live Dashboard

The app automatically displays:

🏆 Top 3 Leaderboard

🥇 Gold
🥈 Silver
🥉 Bronze

🎯 Best Innovation Award

📊 Auto Ranking of all stalls

These rankings update automatically as judges evaluate stalls.

🔟 End Judgement

After evaluating all stalls:

Tap

End Judgement

This will:

Lock editing

Enable the Final Judgement Report PDF

If needed, judges can still:

Unlock Judgement

to modify evaluations.

1️⃣1️⃣ Generating Final Judgement Report

Click:

Final Judgement Report PDF

The system generates a professional report containing:

1️⃣ Expo Cover Page
2️⃣ Top 3 Leaderboard
3️⃣ Best Innovation Award
4️⃣ Complete Stall Ranking
5️⃣ Detailed Evaluation of Each Stall
6️⃣ Judge Signature Page

The report opens in a new window for printing or saving.

1️⃣2️⃣ Returning to the App

After viewing the report:

Click

Close Report

This returns the judge to the application.

1️⃣3️⃣ Data Storage

All stall evaluations are stored locally on the judge's device.

Even if the app is closed:

Previously entered stalls remain saved

Data is restored automatically when reopening the app

1️⃣4️⃣ Clearing All Data

If required, judges can reset the system by clicking:

Clear All Saved

This removes all stored stall evaluations.

⚠️ Use only if the judging session needs to restart.

1️⃣5️⃣ Exporting Data

The system also supports:

Export CSV

This creates a spreadsheet of all stall evaluations.

Useful for:

Organizers

Academic records

Archive storage

1️⃣6️⃣ Recommended Judging Workflow

Before the expo:

Open the app

Enter judge details

Add to mobile home screen

During judging:

Visit stall

Score criteria

Add remarks

Click Save & Next

After judging:

Review leaderboard

Click End Judgement

Generate Final Judgement Report PDF

1️⃣7️⃣ Best Practices for Judges

✔ Score fairly across all stalls
✔ Use remarks to provide constructive feedback
✔ Review rankings before ending judgement
✔ Lock judgement only after final confirmation

📄 Output Report

The final report is suitable for:

Academic records

Official competition results

Award announcements

Institutional documentation
